# 欢迎使用 ARGVUS

今天，我们向大家介绍 **ARGVUS**：一款面向 **Arch Linux**、为 **Wayland** 打造并由 **Hyprland** 驱动的模块化桌面环境。

ARGVUS 将 Linux 桌面的各个部分整合在一起：登录与会话启动、窗口与工作区、任务栏和快捷控制面板、设置、主题、通知、显示器、电源、网络以及日常应用。这些部分被组织成专注于特定功能的软件包，并共享一套配置模型，因此整个桌面体验协调一致，却不会成为一个庞大的单体程序。

> **简而言之：** Arch Linux 是操作系统，Hyprland 是 Wayland 合成器，而 ARGVUS 则围绕它们协调会话与桌面体验。

## 协同工作的桌面组件

ARGVUS 会话从登录到进入桌面，流程清晰明了：

```text
登录或 TTY
    ↓
ARGVUS 会话 → Hyprland
    ↓
任务栏 · 控制面板 · 通知 · 壁纸 · 空闲服务
```

会话管理器负责启动并监督桌面服务。Hyprland 管理窗口、工作区和显示器。任务栏、控制面板、设置应用以及专用服务软件包，提供了你每天使用的界面。

| 领域 | 为桌面带来的功能 |
| --- | --- |
| **登录与会话** | ARGVUS 欢迎界面、图形登录、TTY 启动以及受管理的用户服务。 |
| **窗口与工作区** | 配备键盘快捷键、布局、显示器管理和共享外观设置的 Hyprland 配置。 |
| **任务栏** | 基于 Waybar 的栏，用于显示工作区、窗口和系统状态，并支持可选小组件。 |
| **控制面板** | 基于 Quickshell 的界面，提供快捷操作、会话和电源控制以及桌面小组件。 |
| **控制中心** | 一款优先支持键盘操作的设置应用，用于桌面配置和管理。 |
| **桌面服务** | 面向显示器、网络、蓝牙、电源、通知、防火墙和可移动存储的专用集成。 |

每个组件都有自己的命令和服务行为。这种模块化设计让你可以维护或改进某一部分，而不必把整个桌面变成一个紧密耦合的应用程序。

## 协同工作的设置

更改设置时，桌面各处都应产生可预测的效果。ARGVUS 会集中保存外观与偏好状态，再将其应用到相关组件。控制中心提供了便于引导操作的设置界面；如果你更喜欢终端，也可以使用命令行工具。

例如，更改主题后，合成器、GTK 和 Qt 应用、任务栏、控制面板、启动器、通知和锁屏都可以同步更新。你还可以选择强调色和布局风格：

| 风格 | 特点 |
| --- | --- |
| **Sticky** | 间距紧凑，窗口与桌面界面元素之间更加贴合。 |
| **Spaced** | 间距更大、圆角、阴影，并为桌面外壳留出更多空间。 |

视觉系统包含 **23 个主题系列**，每个系列都提供这两种风格，同时还包含壁纸、字体、图标主题和可配置效果。你可以选择现成的外观，也可以调整强调色，打造自己的风格。

> **请注意这一区别：** 你选择的偏好设置才是事实来源。为各个桌面组件生成的文件只是共享状态的投影，因此请通过 ARGVUS 设置或受支持的命令进行更改，而不要直接编辑生成文件。

## 已集成的实用工具

ARGVUS 包含或集成了一系列小巧实用的功能，让常见任务触手可及：

- **应用启动器：** 按下 `SUPER + D` 查找已安装的图形应用。其他键盘菜单还可以打开项目、SSH 主机、代码片段、表情符号、计算器和速查表。
- **显示器控制：** 查看显示器，并在当前合成器和硬件支持的情况下调整分辨率、刷新率、缩放、位置和方向等设置。
- **电源与会话操作：** 使用控制面板立即锁定、挂起、注销或关机。在控制中心配置持续生效的空闲与显示器行为。
- **勿扰模式：** 在控制面板中控制通知的送达；启用期间收到的通知会保留下来，供稍后查看。
- **可移动设备：** 从集成菜单和任务栏界面访问存储设备操作。
- **ARGVUS Focus：** 启动番茄工作法式的专注时段、休息和通知，并保存本地历史记录。
- **ARGVUS Clock：** 使用世界时钟、秒表、计时器和闹钟，并支持稍后提醒和漏接闹钟报告。
- **终端工具：** 打开已配置的终端配置文件、系统监视器以及其他集成的 TUI 应用。

部分功能以可选软件包的形式提供。例如，可以添加编程代理集成和游戏，而无需将它们作为基础会话的必备组件。AI 集成会在终端中启动你选定的代理；ARGVUS 不会替你创建账户，也不会配置 API 密钥或订阅。

## 在 Arch Linux 上开始使用

在全新安装的 Arch Linux 上，文档提供的快速开始方式如下：

```sh
curl -fsSL https://argvus.github.io/install.sh | sh
```

安装程序会配置 ARGVUS 软件包仓库，并安装 `argvus` 软件包及其依赖项。然后注销，在显示管理器中选择 **ARGVUS**，或从 TTY 启动 ARGVUS 会话。

```sh
# 打开控制中心
argvus --control-center

# 随时重新打开首次设置指南
argvus welcome
```

ARGVUS 面向 **Arch Linux**、**Wayland** 和 **Hyprland**；它不是独立的 Linux 发行版。安装前请查看[安装指南](https://argvus.github.io/docs/getting-started/installation/)，了解系统要求、手动设置方法和最新软件包详情。
