# ARGVUSへようこそ

本日、**ARGVUS**をご紹介します。**Arch Linux**向けに、**Wayland**上で**Hyprland**を採用したモジュール型デスクトップ環境です。

ARGVUSは、Linuxデスクトップを構成する要素をひとつにまとめます。ログインとセッションの起動、ウィンドウとワークスペース、タスクバーとクイックコントロールパネル、設定、テーマ、通知、ディスプレイ、電源、ネットワーク、日常的に使うアプリケーションなどです。それぞれの要素は共通の設定モデルを使う専用パッケージとして構成されているため、巨大な単一プログラムにすることなく、デスクトップ全体に一体感を持たせます。

> **要するに：** Arch Linuxはオペレーティングシステム、HyprlandはWaylandコンポジター、そしてARGVUSはその両方を中心にセッションとデスクトップ体験を調整します。

## 連携して動くデスクトップの構成要素

ARGVUSのセッションは、ログインからデスクトップまで明確な流れで進みます。

```text
ログインまたはTTY
    ↓
ARGVUSセッション → Hyprland
    ↓
タスクバー · コントロールパネル · 通知 · 壁紙 · アイドルサービス
```

セッションマネージャーはデスクトップサービスを起動し、その動作を監視します。Hyprlandはウィンドウ、ワークスペース、モニターを管理します。タスクバー、コントロールパネル、設定アプリケーション、専用サービスパッケージが、日々操作する画面を提供します。

| 分野 | デスクトップに追加される機能 |
| --- | --- |
| **ログインとセッション** | ARGVUSのグリーター、グラフィカルログイン、TTYからの起動、管理されたユーザーサービス。 |
| **ウィンドウとワークスペース** | キーボードショートカット、レイアウト、モニター管理、共通の外観設定を備えたHyprland構成。 |
| **タスクバー** | ワークスペース、ウィンドウ、システム状態を表示するWaybarベースのバー。オプションのウィジェットにも対応します。 |
| **コントロールパネル** | クイック操作、セッションと電源の操作、デスクトップウィジェットを備えたQuickshellの画面。 |
| **コントロールセンター** | キーボード操作を重視した、デスクトップ設定と管理のためのアプリケーション。 |
| **デスクトップサービス** | ディスプレイ、ネットワーク、Bluetooth、電源、通知、ファイアウォール、リムーバブルストレージの専用連携機能。 |

各コンポーネントは、それぞれのコマンドとサービス動作を管理します。このモジュール設計により、デスクトップ全体を密結合したひとつのアプリケーションにすることなく、個別の部分を保守・改善できます。

## 連携する設定

設定を変更したとき、デスクトップ全体で予測可能な結果が得られるべきです。ARGVUSは外観と各種設定の状態を一元的に保存し、必要なコンポーネントに適用します。コントロールセンターには設定を案内する画面があり、ターミナルを使いたい場合はコマンドラインツールも利用できます。

たとえばテーマを変更すると、コンポジター、GTKおよびQtアプリケーション、タスクバー、コントロールパネル、ランチャー、通知、ロック画面をまとめて更新できます。アクセントカラーとレイアウトスタイルも選べます。

| スタイル | 特徴 |
| --- | --- |
| **Sticky** | 余白を抑え、ウィンドウとデスクトップの各領域を近づけた配置。 |
| **Spaced** | 広めの間隔、角丸、影を使い、シェルの周囲にゆとりを持たせた配置。 |

ビジュアルシステムには**23種類のテーマファミリー**があり、それぞれ両方のスタイルで利用できます。壁紙、フォント、アイコンテーマ、設定可能なエフェクトも用意されています。既成の外観を選ぶことも、アクセントカラーを調整して自分好みにすることもできます。

> **覚えておきたい点：** 選択した設定が唯一の基準となる状態です。デスクトップ各コンポーネント向けに生成されるファイルは、その共有状態を反映したものです。生成ファイルを直接編集せず、ARGVUSの設定画面またはサポートされているコマンドから変更してください。

## すぐに使える便利なツール

ARGVUSには、よく使う作業を手早く行える小さな便利機能が含まれているか、統合されています。

- **アプリケーションランチャー：** `SUPER + D`を押すと、インストール済みのGUIアプリケーションを検索できます。追加のキーボードメニューから、プロジェクト、SSHホスト、スニペット、絵文字、計算機、チートシートを開くこともできます。
- **ディスプレイ操作：** モニターを確認し、現在のコンポジターとハードウェアが対応していれば、解像度、リフレッシュレート、スケール、位置、向きなどを調整できます。
- **電源とセッション操作：** コントロールパネルから、ロック、サスペンド、ログアウト、シャットダウンをすぐに実行できます。アイドル時やディスプレイの継続的な動作は、コントロールセンターで設定します。
- **おやすみモード：** コントロールパネルから通知の受信を制御できます。有効中に受信した通知は後で確認できるよう保管されます。
- **リムーバブルデバイス：** 統合メニューやタスクバー画面からストレージ操作にアクセスできます。
- **ARGVUS Focus：** ポモドーロ方式の集中セッション、休憩、通知を利用でき、履歴はローカルに保存されます。
- **ARGVUS Clock：** 世界時計、ストップウォッチ、タイマー、アラームを利用できます。スヌーズや、見逃したアラームのレポートにも対応します。
- **ターミナルツール：** 設定済みのターミナルプロファイル、システムモニター、その他の統合TUIアプリケーションを開けます。

一部の機能はオプションパッケージとして提供されます。たとえば、プログラミングエージェントとの連携やゲームを追加しても、基本セッションに必須の要素にはなりません。AI連携では選択したエージェントをターミナルで起動します。ARGVUSがアカウントを作成したり、APIキーやサブスクリプションを設定したりすることはありません。

## Arch Linuxで始める

Arch Linuxを新規インストールした場合、ドキュメントに記載されたクイックスタートは次のとおりです。

```sh
curl -fsSL https://argvus.github.io/install.sh | sh
```

インストーラーはARGVUSのパッケージリポジトリを設定し、依存関係とともに`argvus`パッケージをインストールします。その後ログアウトし、ディスプレイマネージャーで**ARGVUS**を選ぶか、TTYからARGVUSセッションを起動してください。

```sh
# コントロールセンターを開く
argvus --control-center

# 初回セットアップガイドをいつでも再表示する
argvus welcome
```

ARGVUSは**Arch Linux**、**Wayland**、**Hyprland**向けに作られており、単体で動作するLinuxディストリビューションではありません。インストール前に[インストールガイド](https://argvus.github.io/docs/getting-started/installation/)で要件、手動セットアップ、最新のパッケージ情報を確認してください。
