오늘 **ARGVUS**를 소개합니다. **Arch Linux**를 위한 모듈형 데스크톱 환경으로, **Wayland**용으로 만들어지고 **Hyprland**를 기반으로 합니다.

ARGVUS는 Linux 데스크톱의 여러 요소를 한데 모읍니다. 로그인 및 세션 시작, 창과 작업 공간, 작업 표시줄과 빠른 제어 패널, 설정, 테마, 알림, 디스플레이, 전원, 네트워크, 일상적으로 사용하는 애플리케이션이 포함됩니다. 각 요소는 공통 설정 모델을 공유하는 목적별 패키지로 구성되어 있어, 하나의 거대한 프로그램이 되지 않으면서도 데스크톱 전체가 하나의 시스템처럼 작동합니다.

> **간단히 말해:** Arch Linux는 운영 체제이고, Hyprland는 Wayland 컴포지터이며, ARGVUS는 이 둘을 중심으로 세션과 데스크톱 경험을 조율합니다.

## 서로 협력하는 데스크톱 구성 요소

ARGVUS 세션은 로그인부터 데스크톱까지 명확한 흐름을 따릅니다.

```text
로그인 또는 TTY
    ↓
ARGVUS 세션 → Hyprland
    ↓
작업 표시줄 · 제어 패널 · 알림 · 배경 화면 · 유휴 서비스
```

세션 관리자는 데스크톱 서비스를 시작하고 감독합니다. Hyprland는 창, 작업 공간, 모니터를 관리합니다. 작업 표시줄, 제어 패널, 설정 애플리케이션과 전용 서비스 패키지가 매일 사용하는 화면과 기능을 제공합니다.

| 영역 | 데스크톱에 제공하는 기능 |
| --- | --- |
| **로그인과 세션** | ARGVUS 인사 화면, 그래픽 로그인, TTY 시작, 관리되는 사용자 서비스. |
| **창과 작업 공간** | 키보드 단축키, 레이아웃, 모니터 관리, 공유 외관 설정을 갖춘 Hyprland 구성. |
| **작업 표시줄** | 작업 공간, 창, 시스템 상태를 표시하는 Waybar 기반 표시줄과 선택형 위젯. |
| **제어 패널** | 빠른 작업, 세션 및 전원 제어, 데스크톱 위젯을 제공하는 Quickshell 화면. |
| **제어 센터** | 데스크톱 설정과 관리를 위한 키보드 우선 설정 애플리케이션. |
| **데스크톱 서비스** | 디스플레이, 네트워크, Bluetooth, 전원, 알림, 방화벽, 이동식 저장 장치 연동. |

각 구성 요소는 자체 명령과 서비스 동작을 관리합니다. 이러한 모듈형 설계 덕분에 데스크톱 전체를 서로 밀접하게 결합된 하나의 애플리케이션으로 만들지 않고도 각 부분을 유지 관리하거나 개선할 수 있습니다.

## 함께 작동하는 설정

설정을 변경하면 데스크톱 전체에 예측 가능한 효과가 나타나야 합니다. ARGVUS는 외관과 기본 설정 상태를 중앙에 저장한 다음 해당 구성 요소에 적용합니다. 제어 센터에서는 안내에 따라 설정을 변경할 수 있으며, 터미널을 선호한다면 명령줄 도구도 사용할 수 있습니다.

예를 들어 테마를 변경하면 컴포지터, GTK 및 Qt 애플리케이션, 작업 표시줄, 제어 패널, 런처, 알림, 잠금 화면을 함께 업데이트할 수 있습니다. 강조 색상과 레이아웃 스타일도 선택할 수 있습니다.

| 스타일 | 느낌 |
| --- | --- |
| **Sticky** | 간격이 좁고 창과 데스크톱 표면이 더 가깝게 배치됩니다. |
| **Spaced** | 더 넓은 간격, 둥근 모서리, 그림자와 여유로운 데스크톱 외곽 공간을 제공합니다. |

시각 시스템에는 두 스타일로 제공되는 **23개 테마 계열**과 배경 화면, 글꼴, 아이콘 테마, 조정 가능한 효과가 포함됩니다. 준비된 스타일을 선택하거나 강조 색상을 조정해 원하는 모습으로 만들 수 있습니다.

> **기억할 점:** 선택한 기본 설정이 기준이 되는 원본입니다. 각 데스크톱 구성 요소용으로 생성된 파일은 이 공유 상태를 반영한 결과물입니다. 따라서 생성 파일을 직접 편집하지 말고 ARGVUS 설정이나 지원되는 명령을 사용해 변경하세요.

## 이미 연결된 유용한 도구

ARGVUS에는 자주 하는 작업을 편리하게 수행할 수 있는 여러 기능이 포함되거나 통합되어 있습니다.

- **애플리케이션 런처:** `SUPER + D`를 눌러 설치된 그래픽 애플리케이션을 찾습니다. 추가 키보드 메뉴에서 프로젝트, SSH 호스트, 스니펫, 이모지, 계산기, 치트시트를 열 수 있습니다.
- **디스플레이 제어:** 모니터를 확인하고 현재 컴포지터와 하드웨어가 지원하는 경우 해상도, 새로 고침 빈도, 배율, 위치, 방향 등을 조정합니다.
- **전원과 세션 작업:** 제어 패널에서 잠금, 절전, 로그아웃, 종료를 바로 실행합니다. 지속적으로 적용할 유휴 시간 및 디스플레이 동작은 제어 센터에서 설정합니다.
- **방해 금지:** 제어 패널에서 알림 전달을 제어합니다. 이 기능이 켜져 있는 동안 받은 알림은 나중에 볼 수 있도록 보관됩니다.
- **이동식 장치:** 통합 메뉴와 작업 표시줄 화면에서 저장 장치 작업에 접근합니다.
- **ARGVUS Focus:** Pomodoro 방식의 집중 세션, 휴식, 알림을 실행하고 기록을 로컬에 저장합니다.
- **ARGVUS Clock:** 세계 시계, 스톱워치, 타이머, 알람을 사용할 수 있으며 다시 알림과 놓친 알람 보고도 지원합니다.
- **터미널 도구:** 설정된 터미널 프로필, 시스템 모니터, 기타 통합 TUI 애플리케이션을 엽니다.

일부 기능은 선택형 패키지로 제공됩니다. 예를 들어 프로그래밍 에이전트 연동과 게임은 기본 세션의 필수 구성 요소로 만들지 않고 추가할 수 있습니다. AI 연동은 선택한 에이전트를 터미널에서 실행합니다. ARGVUS가 계정을 만들거나 API 키 또는 구독을 대신 설정하지는 않습니다.

## Arch Linux에서 시작하기

새 Arch Linux 설치에서 문서에 안내된 빠른 시작 방법은 다음과 같습니다.

```sh
curl -fsSL https://argvus.github.io/install.sh | sh
```

설치 프로그램은 ARGVUS 패키지 저장소를 설정하고 의존성과 함께 `argvus` 패키지를 설치합니다. 그런 다음 로그아웃하고 디스플레이 관리자에서 **ARGVUS**를 선택하거나 TTY에서 ARGVUS 세션을 시작하세요.

```sh
# 제어 센터 열기
argvus --control-center

# 언제든지 초기 설정 가이드 다시 열기
argvus welcome
```

ARGVUS는 **Arch Linux**, **Wayland**, **Hyprland**용으로 만들어졌으며 독립형 Linux 배포판이 아닙니다. 설치하기 전에 [설치 안내서](https://argvus.github.io/docs/getting-started/installation/)에서 요구 사항, 수동 설정 방법, 최신 패키지 정보를 확인하세요.
